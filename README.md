# Шлях Потоку

Релігія процесу, свідомості та продовження.

Сайт: https://fil-m.github.io/shliakh-potoku/

Односторінковий сайт із повним текстом — 30 розділів, символ вихора, темна тема. Без зовнішніх залежностей, крім Google Fonts (Cormorant Garamond + Inter). Анімований вихор — canvas, без бібліотек.

## Локальний запуск

```bash
python3 -m http.server 8901
```

## Структура

- `index.html` — весь сайт (HTML + CSS + JS в одному файлі)
